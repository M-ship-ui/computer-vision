# Computer Vision – Day 1

## 25 Python + OpenCV Coding Questions

This repository contains the 25 Day-1 Computer Vision coding questions from the provided practice PDF.

### Technologies
- Python
- OpenCV (`cv2`)
- NumPy
- Matplotlib

### Questions
1. Read and display an image
2. Check image loading
3. Print height, width, channels
4. Calculate total pixels
5. Print image dtype
6. Save with a different filename
7. Read directly in grayscale
8. Convert color to grayscale
9. Display using Matplotlib and hide axis
10. Resize to 50%
11. Access a pixel at `(x, y)`
12. Modify a selected pixel
13. Print B, G, R values
14. Split B, G, R channels
15. Merge three channels
16. Minimum and maximum intensity
17. Mean intensity
18. Mean and standard deviation
19. Create 256×256 intensity-128 image
20. Create intensity ramp 0–255
21. 4-bit quantization
22. 2-bit quantization
23. Downsample by factor 2
24. Crop a rectangular ROI
25. Rotate by 90 degrees

## How to run

1. Install the required libraries:

```bash
pip install opencv-python numpy matplotlib
```

2. Put an image named `sample.jpg` in the repository root.
3. Run each Python file from the repository root.
4. For Q11, Q12, Q13 and Q24, enter valid coordinates when prompted.
5. Output files generated by Q6, Q12, Q24 and Q25 are stored in `outputs/`.
